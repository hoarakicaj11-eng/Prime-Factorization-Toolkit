# Prime Factorization Toolkit

Fast integer factorization tool demonstrating RSA vulnerabilities.

## Algorithms

- **Trial Division**: O(Vn) - finds small factors
- **Polliard's Rho**: O(n^1/4) - probabilistic factorization
